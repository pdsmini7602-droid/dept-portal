# 부서 포털 사용 안내

채용 정보를 한곳에서 보여 주는 부서 포털입니다. 별도 설치 없이 브라우저에서 바로 열 수 있습니다.

## 열어 보기

1. 이 폴더의 `index.html`을 더블클릭합니다. 크롬, 엣지 등 어떤 브라우저든 됩니다.
2. 인터넷 연결 없이도 열립니다.

## 화면 구성

상단 메뉴를 누르면 해당 구역으로 부드럽게 이동하며, 지금 보고 있는 구역의 메뉴가 스크롤에 맞춰 자동으로 강조됩니다.

| 메뉴 | 내용 |
| --- | --- |
| 홈 | 채용 소개, 전형 단계·모집 직무 수, 이번 채용 한눈에 보기 |
| 채용 절차 | 서류 전형부터 최종 합격·입사까지 4단계와 단계별 소요 시간. 아래의 '남은 일수 계산기'에서 날짜를 고르면 오늘부터 남은 일수(D-day)를 알려 줍니다. 입력한 날짜는 저장하거나 외부로 보내지 않습니다 |
| 직무 소개 | IT 서비스 기획, AI·데이터 개발, 사업관리 3개 직무 |
| FAQ | 자주 묻는 질문 4개. 질문을 누르면 답변이 열리고 다시 누르면 닫힙니다. 위쪽 검색창에 키워드를 입력하거나 카테고리 버튼(전체·지원 방법·전형·면접·결과 안내)을 누르면 해당 질문만 보입니다 |
| 자료실 | `files` 폴더의 PDF를 목록(파일명·설명·용량)으로 보여 주고, 내려받기 버튼을 누르면 바로 저장됩니다 |

- 화면 색은 처음에는 컴퓨터의 라이트·다크 모드 설정을 따릅니다. 상단 오른쪽의 달·해 모양 버튼을 누르면 직접 전환할 수 있고, 선택한 모드는 이 브라우저에 저장되어 다음에 열 때도 유지됩니다.
- 아래로 스크롤하면 오른쪽 아래에 ↑ 모양의 '맨 위로' 버튼이 나타나며, 누르면 페이지 맨 위로 부드럽게 올라갑니다.
- 휴대폰처럼 폭이 좁은 화면(760px 이하)에서는 상단 메뉴가 ≡ 버튼으로 접힙니다. 버튼을 누르면 메뉴가 펼쳐지고, 항목을 누르면 해당 구역으로 이동하면서 메뉴가 자동으로 닫힙니다. 메뉴 바깥을 누르거나 Esc 키를 눌러도 닫힙니다.
- 그 밖의 레이아웃(히어로 1단, 채용 절차 2열, 직무 카드 1열)도 좁은 화면에 맞게 바뀝니다.

## 폴더 구조

```
index.html                       포털 화면 (이 파일을 엽니다)
README.md                        이 안내문
files/
  talent-culture-guide.pdf       인재상·조직문화 소개서
  job-posting-2026-h1.pdf        2026년 상반기 채용공고
이전버전/
  portal-v2.html                 이름을 바꾸기 전 원본 사본
```

자료실의 내려받기 버튼은 `files/영문파일명.pdf`를 가리키며, 저장될 때는 한글 파일명(예: 인재상_조직문화_소개서.pdf)으로 저장됩니다.

## FAQ 추가하기

`index.html`에서 `<details class="faq-item" data-category="...">` 블록 하나를 복사해 질문과 답변을 고칩니다. `data-category` 값은 `apply`(지원 방법), `process`(전형·면접), `result`(결과 안내) 중 하나입니다. 검색은 질문과 답변 글 전체에서 찾습니다.

## 자료 추가하기

1. 새 파일을 `files` 폴더에 영문 소문자와 하이픈 이름으로 넣습니다.
2. `index.html`에서 `<li class="file-item">` 블록 하나를 복사해 붙이고 파일명, 설명, 용량, 링크(`href="files/...")`, 저장 이름(`download="..."`)을 고칩니다.

## 수정하는 방법

- 글은 `index.html`을 메모장 등 텍스트 편집기로 열어 `<main>` 안의 문장을 고칩니다.
- 색·글꼴·여백은 파일 앞쪽 `<style>` 안의 `:root` 값(`--bg`, `--blue` 등)을 고치면 전체에 반영됩니다.
- 수정 전에는 파일을 한 부 복사해 두시길 권합니다.

## 파일 이름 규칙

영문 소문자와 숫자, 하이픈(`-`)만 쓰고 한글과 공백은 쓰지 않습니다. 예: `job-posting-2026-h1.pdf`
