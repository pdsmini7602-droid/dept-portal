# 유진기업 하우징플랫폼 포털 사용법

최종 갱신: 2026-11-23

## 폴더 구성
```
우리부서포털/
├─ index.html            포털 본체 (더블클릭하면 브라우저에서 열림)
├─ files/                자료실에 올라가는 파일
│   ├─ customer-support-guide.pdf   (고객지원_안내서.pdf)
│   └─ product-service-intro.pdf    (제품서비스_소개서.pdf)
├─ 이전버전/             원본 보관본
├─ README.md             이 문서
└─ release-checklist.md  공개 전 점검 체크리스트
```
`index.html`과 `files` 폴더는 항상 같은 위치에 두어야 다운로드가 동작합니다.

## 화면 구성
상단 메뉴: 홈 · 제품 소개 · 착공·수주 · 자재 시황 · 견적 계산기 · FAQ · 자료실. 지금 보는 영역의 메뉴가 강조됩니다.

- **모바일 메뉴**: 화면 폭 820px 이하에서는 ≡ 버튼으로 접힙니다. 항목을 누르면 이동하면서 자동으로 닫히고, 바깥을 누르거나 Esc를 눌러도 닫힙니다.
- **화면 모드**: 오른쪽 위 버튼으로 다크/라이트를 전환합니다. 기본은 다크이고, 선택은 이 브라우저에만 저장됩니다.
- **맨 위로**: 화면을 내리면 오른쪽 아래에 ↑ 버튼이 나타납니다.

## 착공·수주 영역
- 국토부 주택통계(착공·인허가·분양·준공), 지역별 누계, 월별 흐름을 보여 줍니다.
- **주요 착공·시공 건**은 서울 아파트 정비사업 위주입니다.
  - ① 서울시 공식 착공 통계 (시공사는 해당 통계에 없어 '확인 필요'로 표시)
  - ② 대기업 시공사가 정해진 서울 아파트 재건축 (착공 전 단계)
- 시공사 선정·도시정비 수주 현황은 시평 상위 10개사 기준입니다.
- 수치는 기준일이 있는 자료입니다. 공개 전에 갱신해 주세요.

## 견적 계산기
- **품목별 견적**: 수량을 입력하면 합계, 물량 할인, 운송 옵션이 반영된 예상 금액이 나옵니다. 단가와 할인율은 샘플 값입니다.
- **견적서 메일 발송**: 입력한 내용으로 메일 본문을 만들어 메일 프로그램(mailto)을 엽니다. 받는 사람은 직접 입력합니다. 기본 받는 사람을 두려면 `index.html`의 `SALES_EMAIL` 값에 이메일을 넣으세요.
- **철근 예상 금액 계산**: 철근 톤수를 입력하면 공급가액, 부가세 10%, 합계를 보여 줍니다. 톤당 단가 기본값 765,000원은 자재 시황의 국산 철근 유통시세 중간값이며 직접 바꿀 수 있습니다. 시황이 바뀌면 `rc-price`의 `value` 값을 같이 수정하세요. 운송비와 규격별 가격 차이는 포함하지 않습니다.

## FAQ 검색
검색창에 키워드를 입력하거나 카테고리 버튼을 누르면 해당 FAQ만 보입니다. 두 조건은 함께 적용됩니다. 띄어쓰기로 여러 단어를 넣으면 모두 포함된 항목만 나옵니다. Esc 또는 '지우기'로 검색어를 지웁니다. FAQ 내용은 `index.html`의 `FAQS` 목록에서 고칩니다.

## 자료실 파일 추가
1. 파일명을 영문 소문자와 하이픈으로 정해 `files` 폴더에 넣습니다. (예: `price-list-2026.pdf`)
2. `index.html`에서 `const FILES = [` 부분을 찾아 한 줄을 추가합니다.
```js
{tag:"PDF", saveAs:"가격표_2026.pdf", desc:"설명", size:"약 120KB", href:"files/price-list-2026.pdf"},
```
- `href`는 `files/파일명` 상대 경로, `saveAs`는 내려받을 때 저장되는 한글 파일명입니다.
- 다운로드 버튼에 `download` 속성이 있어 PDF도 새 창 없이 바로 저장됩니다.

## 개인정보
- 견적 계산기, 철근 계산기, 메일 작성창에 입력한 내용은 저장하거나 서버로 보내지 않습니다.
- 메일 보내기는 사용자의 메일 프로그램을 여는 방식이라, 보내기 전까지는 어디에도 전달되지 않습니다.
- 브라우저에 저장되는 것은 화면 모드(다크/라이트) 선택 하나뿐입니다.

## 공개 전에 꼭 확인할 것
자세한 항목은 `release-checklist.md`를 보세요. 특히 아래 두 가지는 공개 전에 해결해야 합니다.
- 자료실 PDF 2개는 "샘플·실제 업무 사용 금지"로 표기된 교육용 문서입니다. 승인된 실제 문서로 교체하세요.
- FAQ 10건은 샘플 문서 내용에서 나온 것이라 건자재 업무 기준으로 확인·수정해야 합니다.
